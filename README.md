# ✦ AnimeWallora — Anime wallpapers for everyone

![Website smoke tests](https://github.com/eliron8565/Wallpapers/actions/workflows/test-site.yml/badge.svg)

An English-language open-source gallery for anime-inspired, fantasy, manga and animated wallpapers. Built with HTML, CSS and vanilla JavaScript, deployed on GitHub Pages, with media hosted in Cloudflare R2.

**Site:** https://eliron8565.github.io/Wallpapers/

## What the site includes

- Immersive, mobile-responsive visual design and curated artwork collection
- **11 real independently created fantasy/manga illustrations** from Wikimedia Commons by **David Revoy** and **Niabot**
- **25 embedded GIPHY animations** — played on the site, served and credited by GIPHY
- Fullscreen previews, artist/source/license details, filters, search, favorites saved in the browser
- Cloudflare R2 hosting for Commons files with eligible verified open licenses
- Automated catalog validation and website smoke tests
- Owner-triggered workflow for additional images / videos with appropriate reuse permission

These artworks are **not AI-generated by this project**. This is a gallery of *independent* anime/manga art; do not assume it contains official licensed franchise wallpapers.

## Publishing new wallpapers

**A. Verified Wikimedia Commons files:** Add a catalog entry to `data/wallpapers.json` with `filename`, `source`, `creator`, `license`, `licenseUrl`, `permission: "open-license"`, `type: "image"`. After the file and stated license are checked against the official Commons API, the [Sync approved Commons anime art to R2](.github/workflows/sync-commons-r2.yml) workflow uploads it to R2 and updates the URL in the catalog.

**B. Other explicitly authorized files:** Go to Actions → [Publish licensed anime wallpaper to R2](.github/workflows/publish-wallpaper.yml) → Run workflow. Provide a *direct HTTPS media file URL*, title, source, creator, specific license and authorization basis. It is **not** a bulk scraper; only rights-cleared media should be submitted.

**C. From ChatGPT:** When the repository connector is available, ask ChatGPT to update the project and submit source files that have appropriate redistribution licenses or permission. The GitHub Actions pipeline uses secrets saved in the repo; never paste API keys in the chat.

## Cloudflare R2

Bucket: `animewallora-media`. The automated workflows use repository secrets:
`R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`; and repository variable `R2_PUBLIC_URL`.

The temporary `.r2.dev` development URL has request limits and is **not** recommended for a busy production website. Later attach a Cloudflare custom domain. R2 storage has a limited free tier; check Cloudflare billing for operations and storage. See [MEDIA_SETUP.md](MEDIA_SETUP.md).

**CORS note:** JavaScript downloads work when the public host allows cross-origin GET requests from your GitHub Pages origin. Without CORS, clicking download opens the image URL so the visitor can save it manually. See Cloudflare R2 settings → CORS Policy, and consider `GET` and `HEAD` for `https://eliron8565.github.io`.

## Running locally

Open `index.html` through a local HTTP server (e.g., `python -m http.server 8000`). The site loads `data/wallpapers.json` using `fetch`; running directly from a `file://` URL may block local fetch requests.

No JavaScript frameworks, build step, API tokens or private credentials are shipped to website visitors.
